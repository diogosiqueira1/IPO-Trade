03 / GEOMETRIA CHANFRADA

A Anatomia do .cut-corner

Preview do Box Chanfrado

A geometria chanfrada com 17px de chanfro utiliza polígonos CSS otimizados para GPU, proporcionando a identidade futurista do IPO Trade.

.cut-corner • 17px clip-path
cut-corner.css 
.cut-corner {
  clip-path: polygon(
    17px 0%,
    calc(100% - 17px) 0%,
    100% 17px,
    100% calc(100% - 17px),
    calc(100% - 17px) 100%,
    17px 100%,
    0% calc(100% - 17px),
    0% 17px
  );
}
