REGULAÇÃO BACEN & SEC

A Anatomia do .cut-corner

Utiliza polígonos CSS com clip-path: polygon() sobrepostos nos 4 cantos de qualquer container para criar o icônico efeito chanfrado de 17px (desktop) e 13px (mobile) do Spade.

CHANFRO DE 24PX

Superfície Chanfrada

Qualquer cor de fundo ou imagem pode ser utilizada. As sobreposições cortam os 4 cantos perfeitamente.

05 / EXPORTAÇÃO & PACOTE DE ARQUIVOS

Baixe o Design System Completo

Acesse diretamente as folhas de estilo CSS, scripts de animação JS e o pacote JSON com todos os tokens estruturados.

CSS

design-system-ds2.css

Folha de estilo completa com todos os tokens, variáveis de cor, regras do .cut-corner, réguas de medição e classes tipográficas.

JS

design-system-ds2.js

Script com motor de partículas em canvas, contadores animados NumberFlow, gerenciador de modais e utilitários de cópia.

JSON

ds2-tokens.json

Dicionário JSON de tokens compatível com Figma Tokens Studio, Tailwind CSS e pipelines de CI/CD.

Como incluir no seu projeto: 
<!-- Incluir no <head> -->
<link rel="stylesheet" href="css/design-system-ds2.css">

<!-- Incluir antes do fechamento do </body> -->
<script src="js/design-system-ds2.js"></script>
